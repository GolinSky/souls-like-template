# Souls-Like Game Template

A comprehensive **Unity project template** designed for building **Souls-like** action RPG games.

## Overview

This repository serves as a starter template and foundation for developing Souls-like mechanics in Unity. It includes core game systems such as character control, combat, camera setups, and animation frameworks suitable for third-person action RPG games.

## Requirements

- **Unity Version**: Unity 6 (6000.3.11f1) or compatible
- **Render Pipeline**: High Definition Render Pipeline (HDRP)

## Features

- Third-person player character controller
- Lock-on & target tracking
- Melee combat and stamina/health management
- Modular architecture built for extensibility

## Getting Started

1. Clone or download this repository.
2. Open the project folder in **Unity Hub** using **Unity 6** (or newer).
3. Load the default main scene in `Assets/` to test out the project.
